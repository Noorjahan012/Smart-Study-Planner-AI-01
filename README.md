
# 📚 Smart Study Planner with AI Coach

A simple Python project that helps students plan their study schedule smartly and gives useful AI-based study tips.

---

## 🚀 Features

* Take input of subjects, hours, and priority
* Create a smart daily study plan
* Estimate total days needed
* Show study distribution graph
* Give AI study tips for each subject

---

## 🛠️ Tech Used

* Python 🐍
* Pandas 📊
* Matplotlib 📈
* Math module ➗

---

## ▶️ How to Run

```bash
pip install pandas matplotlib
python smart_study_planner.py
```

---

## 📌 How It Works

1. Enter subjects, hours, and priority
2. Set daily study limit
3. Get a smart schedule
4. View study graph
5. Get AI study suggestions

---

## 🧠 AI Coach

* Suggests best time to study
* Gives study methods (revise, practice, read)
* Memory tips (flashcards, active recall)
* Focus and diet tips

---

## 💡 Output

* Study schedule by day
* Total and estimated days
* Graph of study hours
* Smart AI recommendations

---

A simple smart study planner to improve focus and productivity.
